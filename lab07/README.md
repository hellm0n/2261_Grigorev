### Задание 1 **(2)**
*Оцените работу следующих фрагментов программ. Какие из них обладают неоднозначным поведением? Почему?*
```
int x=10, y=3;
std::cout << std::min(x=15, x+y);
```
```
int x=10, y=3;
x=15, y+=x, x+=y;
```
```
int x=10, y=9;
if (x>y++ && y++>9)
  cout << "yes" << endl;
cout << y;
```

*Тексты программ разместите в папке с номером задания*

**Ответ:**

1. Неоднозначное поведение, т.к. компилятор может вычислять аргументы в любом порядке. Слева направо: `x` становится `15`, далее `x+y` вернет `18`, результатом будет `15`. А если справа налево: `x+y` вернет `13`, а потом `x` станет `15`, результат функции будет `13`.
2. Однозначное, т.к. запятая гарантирует вычисления слева направо.
3. Однозначное, т.к. оператор `&&` всегда выполняется слева направо. `x>y` вернет `true`, а значит начнётся проверка `y++>9`, которая вернёт `false`, потому что постфиксный инкремент сначала отдаст текущее значение, а потом увеличит. Поэтому `yes` не выведется.

### Задание 4 **(2)**

*Почему присваивание* ```(++x)=y``` *является синтаксически правильным, а*
```(x++)=y``` - *нет? Запишите текст сообщения об ошибке, переведите и объясните его.*

**Ответ:**

`error: lvalue required as left operand of assignment`

`(++x)` это lvalue. Под капотом он увеличит переменную, а потом вернёт её.

`(x++)` это rvalue. При выполнении, он сначала вернёт копию старого значения, а саму переменную увеличит после. То есть в этот момент `x` - временное старое значение. Поэтому появляется ошибка, нельзя присвоить что-то временному значению.

### Задание 6 **(2)**

### Задание 7 **(2)**

*Как работает следующая программа? Как зависит результат от исходного значения?*
```
int x;
std::cin >> x;
x-->0 && x-->0 && x-->0 && x-->0 && x-->0;
std::cout << x;
```

**Ответ:**

`x-->0` - это декремент + сравнение: `(x--)>0`. сначала сравнится исходное значение `x` с `0`, потом `x` уменьшится и пойдет следующая проверка, если предыдущая вернула `true`. И так до конца.

### Задание 8 **(3)**

*Какое число выводит следующий фрагмент программы? Посчитайте результат без использования
вычислительной техники. Отчет должен содержать процесс вычислений.*
```
int s = 0;
for (int i = 0, j = 5;i+j <= 16;(i<j ? i : j)++)
   (s += i) += j;
std::cout << s;
```

**Ответ:**

* Итерация 1: 
  * `0 + 5 <= 16` -> true
  * `s += 5` -> s == 5
  * `0 < 5` -> true -> `i = 1`, `j = 5`
* Итерация 2:
  * `1 + 5 <= 16` -> true
  * `s += 6` -> s == 11
  * `1 < 5` -> true -> `i = 2`, `j = 5`
* Итерация 3:
  * `2 + 5 <= 16` -> true
  * `s += 7` -> s == 18
  * `2 < 5` -> true -> `i = 3`, `j = 5`
* Итерация 4:
  * `3 + 5 <= 16` -> true
  * `s += 8` -> s == 26
  * `3 < 5` -> true -> `i = 4`, `j = 5`

И так ещё 8 итераций. В итоге будет `126`. На 6 итерации `i` и `j` окажутся равными (5), поэтому увеличится `j`, потом `i` на 7. И так поочерёдно до конца цикла.

###  Задание 9 **(3)**
*Рассмотрите следующую программу. Предполагается, что на вход подается некоторый
индекс в массиве - число от нуля до девяти и значение, которое надо записать по этому индексу.*
```
int i = 0;
std::vector<int> x(10);
std::cin >> i >> x[i];
std::cout << x[i];
```
*Проверьте работу этой программы на различных компиляторах. Найдите два компилятора (можно 
проверить онлайн компиляторы), на которых эта программа будет давать различные ответы при одинаковом
вводе. Как это объяснить?*

**Ответ:**

На старых компиляторах (gcc + c++14) здесь могло быть выполнение справа налево. То есть сначала `x[i]`, где i всё еще равно 0, а только потом `>> i`. В итоге вывод был бы 0, потому что значение установилось на нулевом индексе.

В более новых версиях gcc выполнение всегда идёт слева направо.

*Найдите и объясните примеры "коварных" ошибок программистов на С++, связанных с вычислением выражений. 
Каждый пример оценивается в два балла. Примеры из лекции или из заданий не засчитываются.*

**Ответ:**

**Целочисленное деление**
```cpp
double n = 0.0;
int x = 10;

n = (x - 1) * (5 / 9); 
```
Здесь при любом x будет 0, потому что деление `5 / 9` всегда будет возвращать 0, ведь `5` - int. Чтобы это сработало, нужно изменить на double, то есть `5.0 / 9`.

**Беззнаковые числа**
```cpp
std::vector<int> v;
for (int i = 0; i < v.size() - 1; ++i) { }
```
`size()` возвращает `unsigned int`. Если длина вектора будет 0, то `v.size() - 1` приведёт к переполнению (2^32-1) и цикл начнёт итерироваться до i == 2^32-1.
