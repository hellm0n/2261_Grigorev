### Задание 3 **(2)**

*Проверьте работу следующего фрагмента программы на С++.*
```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

**Ответ:**
Во вложенном цикле, внешняя `i` скрывается вложенной `i`. Вложенный отработает 3 раза и `i` получится 3. После этого внешняя `i` вернется, прибавится 0 и так ещё 3 раза. В итоге внутренний цикл добавит 12, а внешний 4. Получится 18.

### Задание 4 **(2)**

*Проверьте работу следующего фрагмента программы на* **Python**.
```
s = 0
for i in range(4):
   for i in range(3):
      s += i
   s += i
print(s)
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

*На основе этих примеров поясните различия между* **С++** и **Python** *при работе с переменными*.

**Ответ:**
Здесь во вложенном цикле будет 3, но переменная вложенная `i` не замещает внешнюю, это одна и та же переменная. Поэтому в строке после цикла будет `s += 2`. На следующей итерации `i` перезапишется на 1, но вложенный так же будет начинаться с нуля. В итоге получится `20`.

### Задание 5 **(2)**

*Напишите свой пример программы на* **С++**, *создающий и использующий пространства имен. Программа
должна содержать не менее двух пространств имен.*

###  Задание 9 **(3)**
*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*

**Ответ:**
```py
import string

value = 1

for letter in string.ascii_lowercase:
    for num in range(100):
        varName = f"{letter}{num}"
        globals()[varName] = value
        value += 1
```
